# Margin Notes — The Price of Saving Face

The Significant Five · STA304 · University of Toronto Mississauga

[Open the public Shiny website](https://01a21deb-dfb2-738b-8d2c-e8fbeecb7795.share.connect.posit.cloud/)

The app presents 92 students’ survey responses about spending and everyday embarrassment. Choose a figure, filter by student status, and change the currency measure, axis units, or colours. The amount charts show grouped distributions. The full-study rank correlation uses the original paired answers.

## Run locally

Open `website/app.R` in RStudio and click **Run App** with the `shiny` package installed. The `website` directory includes the R source, aggregate data, display assets, and dependency manifest for the published version.
